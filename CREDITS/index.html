    Credits¶

    Everyone whose work is in this fork, and every project it took something from. Everyone listed under People and Help and testing also appears in the launcher's About section. Components and their licenses: bbport's notes.

    Projects¶

    Project What this fork takes from it
    deadinside28/bloodborne_pc bbport, the native Linux port everything here is built on. Its README is here.
    Supermedo/bloodborne_pc The Windows port: online play, DLSS, the cheats page, Add to Steam, the icon, the direct mouse camera, ultrawide, Quit to Desktop, the keyboard sprint and many fixes.
    Awakenchan/LanternEngine (formerly BloodBorneButPc) Lantern Engine by Awaken (https://github.com/Awakenchan/LanternEngine) (GPL-3.0-or-later): video memory on 4 GB cards, crash and freeze fixes, fewer stutters while areas load, stick options, save import and the version selector.
    shadPS4 The renderer and shader recompiler, and the online code.
    Wozzardman/shadp2p The network and PSN libraries for online play.
    Wozzardman/shadnet-p2p The shadNet server for a group's own co-op server (hosting your own server).
    MaskZeus/bbbridge Co-op on The Hunter's Dream's pool (bbbridge/).
    Classmg22/BBSC Seamless Co-op, by CLS_AMG, with Wozzardman's seamless summon (bbsc/).
    fhody125-web/NoDreamForHunter The base of BBSC's game server.
    MikeTat1988/HuntersAtlas Hunter's Atlas: the fullscreen in-game map, its quick-menu tile, lamp travel and the map generator (tools/hunters-atlas), which runs with Grimrukh's soulstruct.
    The Hunter's Dream The online server, by droogie and its team; droogie's bbhost also brought fast loading after a death or travel.
    IFreemz/shadPS4-Bloodborne-DLSS-FSR The groundwork for DLSS, and the FSR 4 model without trails.
    NVIDIA DLSS SDK DLSS.
    FireBurn/FSR-Vulkan FSR 3.1, with the AMD FidelityFX SDK.
    pkgforge-dev/Anylinux-AppImages quick-sharun, which builds the AppImage.
    paulomanrique/ps4-pkg-extractor The launcher's Install from PKG, on orbis-pkg-util.
    herumi/xbyak, fmtlib/fmt Used by BBSC's Linux build.
    GoldHEN_Patch_Repository Game patches by Kyo, Lance McDonald, auser1337, illusion, emoose and the Bloodborne community: high frame rates, resolution, ultrawide and more.
    Nexus Mods: mod 30 Dommo's Xbox and Switch button prompts and stripped-down gestures menu, uploaded by goomab (assets/menu_prompts).
    Nexus Mods: mod 537 Abken's KBM Icons Generator, which showed which textures keyboard prompts need (after mod 460).
